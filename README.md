# Stitch Vertical Feed Vue

Vue 3 + Vite + Tailwind CSS restoration of the Stitch project:

https://stitch.withgoogle.com/projects/2982813652353387172

The implementation uses Stitch MCP exported HTML/screens as the fidelity baseline and rebuilds the `Discover` page plus the companion `Vertical Feed` screen as an interactive frontend.

## Stack

- Vue 3
- Vite
- TypeScript
- Tailwind CSS
- GitHub Pages
- Vercel

## Local Development

```bash
npm install
npm run dev -- --port 5174
```

## Build

```bash
npm run build
```

For GitHub Pages:

```bash
npm run build:github
```
